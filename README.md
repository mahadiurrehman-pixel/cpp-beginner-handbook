## 📖 About This Book

This is not a reference manual. This is a **journey**.

Most programming books assume you already know something. This one assumes you know *nothing* — and that's exactly right, because everyone starts from zero. Every concept is explained with real-life analogies, every line of code is commented, every mistake is warned about before you make it, and every practice problem comes with a complete solution.

By the end of this book you will:

- ✅ Understand how computers actually think
- ✅ Write real C++ programs from a blank file
- ✅ Master Object-Oriented Programming (the right way)
- ✅ Use the STL like a practitioner, not a tourist
- ✅ Build **3 complete projects** you can show to friends, teachers, and interviewers
- ✅ Read compiler errors without fear (this alone is worth the price of admission)

## 🚀 How to Read This Book

1. **Read in order.** Each chapter builds on the previous one. Skipping ahead = confusion.
2. **Type every code example by hand.** Copy-paste teaches your eyes. Typing teaches your brain.
3. **Attempt every exercise before reading its solution.** The struggle *is* the learning.
4. **Celebrate errors.** Every red error message is the compiler teaching you something.
5. **Come back when stuck.** If a concept doesn't click, move on and return later — it will.

> 📌 **NOTE:** Chapter practice problems have full solutions at the end of each chapter. The files in `exercises/` are *bonus* problem sets — they deliberately ship **without** solutions. Attempt them honestly, then verify your program by running it. If it compiles and the output matches, your solution is correct. That's the real test.

## 💻 Running the Companion Code

Every file in `code/` is a complete, runnable program.

```bash
# Compile (any example)
g++ code/hello-world.cpp -o hello

# Run on Windows
hello

# Run on Mac / Linux
./hello
```

No compiler installed yet? Use an online compiler (see **Chapter 1**) — paste any file's code and hit Run.
