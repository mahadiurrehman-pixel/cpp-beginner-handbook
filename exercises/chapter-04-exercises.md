# Extra Practice — Chapter 4: Operators

```
Problem X4.1 ⭐
Read an integer n. Print n, n+1, n+2, n+3 — using ++ operators
four times, sequencing carefully. Test with n=10.

Problem X4.2 ⭐
Read two ints and print the remainder of the bigger divided by
the smaller (assume second is smaller; no if needed).

Problem X4.3 ⭐
Read a number of days and print years, weeks, and leftover days
(1 year = 365 days, 1 week = 7 days). Input 400 → "1 y 5 w 0 d".

Problem X4.4 ⭐⭐
Read an integer and print 1 if it is positive AND even,
0 otherwise — no if statements, pure logic in a bool.

Problem X4.5 ⭐⭐
Financial: read salary and expenses; print savings, savings as
a percentage, and (savings > expenses) as 1/0.

Problem X4.6 ⭐⭐
Demonstrate pre/post difference: for x=10, print
x++, then x, then ++x, then x — predict each line in comments
BEFORE running. Were you right?

Problem X4.7 ⭐⭐
Read a number of minutes; print hours and minutes
("130 → 2h 10m").

Problem X4.8 ⭐⭐⭐
Read a 4-digit year-like number (e.g. 2026). Print the sum of
the first two digits and the last two digits separately, then
compare them with == and print the bool result.
(2026: 2+0 vs 2+6 → 2 vs 8 → 0)

Problem X4.9 ⭐⭐⭐
Bit lab: read n. Print n<<2 and n>>2 and explain (in comments)
what arithmetic each performs. Also print n & 3 and explain
what that extracts.

Problem X4.10 ⭐⭐⭐
"Shipping rules": read weight (kg) and isExpress (y/n).
Eligible for free shipping when weight <= 5 (any mode) OR
(weight <= 15 AND NOT express). Print the bool result, plus a
second bool for "surcharge applies" (weight > 20, regardless).
```

💡 **Stuck?** Break big conditions into named bools first (see the Mini Challenge solution in Chapter 4).
