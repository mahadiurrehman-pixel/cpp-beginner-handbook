# Extra Practice — Chapter 2: Your First C++ Program

> 🎯 **Bonus problem set.** Chapter problems + solutions live in [chapter-02-first-program.md](../chapter-02-first-program.md).
> ⚠️ **No solutions here by design** — your program's correct output is the verification.

```
Problem X2.1 ⭐
Print a poem of 4 lines about programming. One cout per line,
one blank line between stanzas using an extra endl.

Problem X2.2 ⭐
Print the numbers 1 to 5 with words:
1 is one
2 is two
...

Problem X2.3 ⭐
Print the result of (10 + 5) * 2 and 10 + 5 * 2 on two labeled
lines, letting C++ compute both. Note the difference in a comment.

Problem X2.4 ⭐⭐
Print a 5-column table of "n, n*2, n*3" for n = 1..4 using \t:

n       x2      x3
1       2       3
2       4       6
...

Problem X2.5 ⭐⭐
Print this EXACT text (watch the quotes and backslash!):
The file is at C:\new\test.txt
She said, "Use \"escaped\" quotes."
It's 100% legitimate.

Problem X2.6 ⭐⭐
Make an ASCII "loading bar":
[..........] 0%
[###.......] 30%
[##########] 100%

Problem X2.7 ⭐⭐⭐
Draw an ASCII rocket (at least 8 lines): nose cone, body with
a window, and flames at the bottom.

Problem X2.8 ⭐⭐⭐
Print a "software installation" screen with a fake progress
report, borders, version number, and a success message.
```

💡 **Stuck?** Re-read the escape-sequence table in Chapter 2 — 90% of these are `\t`, `\\`, `\"` tricks.
