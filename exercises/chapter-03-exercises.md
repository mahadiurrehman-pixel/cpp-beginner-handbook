# Extra Practice — Chapter 3: Variables & Data Types

> 🎯 **Bonus problem set.** Chapter problems + solutions live in [chapter-03-variables.md](../chapter-03-variables.md).
> ⚠️ **No solutions here by design** — correct output = correct solution. (No cin yet — set values in code.)

```
Problem X3.1 ⭐
Declare one variable of every basic type describing a book
(title, pages, price, first letter of genre, isAvailable).
Print a labeled "inventory card".

Problem X3.2 ⭐
Store 3 exam scores, compute the total and print whether the
total is above 250 as 1/0 (store the comparison in a bool).

Problem X3.3 ⭐
Use sizeof() on EVERY type from the chapter and print the
results as a tidy table.

Problem X3.4 ⭐⭐
A phone costs Rs. 45,999. Compute and print the price after a
12% discount, using a const for the discount rate. Show both
the discount amount and the final price.

Problem X3.5 ⭐⭐
Store seconds = 7384. Print it as "X hours Y minutes Z seconds"
using ONLY int division and modulo.

Problem X3.6 ⭐⭐
Demonstrate the difference between float and double precision:
store 1.0/3.0 in each and print. Which keeps more digits?

Problem X3.7 ⭐⭐
Char arithmetic: print the 3rd letter AFTER 'K' (use + cast),
and the letter 2 positions BEFORE 'X'. Also print 'A' + 26.

Problem X3.8 ⭐⭐⭐
Movie night budget: 4 friends, tickets Rs. 800 each, snacks
Rs. 1250 total, split all costs EQUALLY. Print cost per person
with 2 decimals, using proper types (no int chopping!).

Problem X3.9 ⭐⭐⭐
Year facts: given birthYear = 2007, compute age in 2026, age
in months (approx), and heartbeats so far at ~70 beats/min
(approx). Which type MUST you use for heartbeats, and why?
(Write the reason as a comment.)

Problem X3.10 ⭐⭐⭐
The "cast trap": compute double x = (int)3.99 + (int)2.99;
and double y = 3.99 + 2.99; — print both and explain the
difference in a comment.
```

💡 **Stuck?** The traps are usually (a) int division and (b) int overflow. Re-read Example 3.4.
