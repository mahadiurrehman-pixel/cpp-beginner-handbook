```
Problem X8.1 ⭐
Read 10 ints; print only those STRICTLY greater than the average.

Problem X8.2 ⭐
Read 8 ints; print the array with neighbors swapped pairwise:
1 2 3 4 → 2 1 4 3.

Problem X8.3 ⭐
Read 6 ints; LEFT-shift all elements by one (first moves to last):
1 2 3 → 2 3 1.

Problem X8.4 ⭐⭐
Find the longest run of equal consecutive values; print value+length.
10 10 4 4 4 2 → value 4, length 3.

Problem X8.5 ⭐⭐
Frequency map without map: read N(≤50) ints each in range 0-20;
print each value 0-20 with its occurrence count (use a counts[21]).

Problem X8.6 ⭐⭐
Merge two sorted 5-element arrays into one sorted 10-element array
in ONE forward pass (two-finger walk: compare fronts, emit smaller).

Problem X8.7 ⭐⭐
Matrix transpose for a 3×3: swap m[i][j] with m[j][i] (i<j only!)
and print before/after.

Problem X8.8 ⭐⭐⭐
"Stock profit": given 7 daily prices, find the max profit from
ONE buy then a LATER sell (scan keeping lowest-so-far).
7 1 5 3 6 4 → buy 1 sell 6 = 5.

Problem X8.9 ⭐⭐⭐
Rotate a 3×3 matrix 90° clockwise and print it.
1 2 3 / 4 5 6 / 7 8 9  →  7 4 1 / 8 5 2 / 9 6 3

Problem X8.10 ⭐⭐⭐
"Missing number": input 9 numbers which are 1..10 with exactly
one missing, find it (hint: expected sum 55 minus actual sum).
```
