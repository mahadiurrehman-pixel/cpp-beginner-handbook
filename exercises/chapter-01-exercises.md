# Extra Practice — Chapter 1: Setting Up Your Environment

> 🎯 **Bonus problem set.** These are *extra* — the chapter's own problems (with solutions) live in [chapter-01-setup.md](../chapter-01-setup.md).
> ⚠️ **No solutions provided here on purpose.** A task is "solved" when it actually works on your machine — that IS the check.

```
TASK 1.1 ⭐  — Create a dedicated folder for this entire book
              (e.g. cpp-journey/) and put ALL future code inside it.
TASK 1.2 ⭐  — In one terminal session: check your compiler version,
              then create + compile + run a file named version-test.cpp
              that prints it too.
TASK 1.3 ⭐  — Compile the same file twice with different -o names
              and run both executables.
TASK 1.4 ⭐⭐ — Intentionally write a program with 3 errors, compile,
              and write down the exact first error message. Fix them
              one at a time, recompiling after each fix.
TASK 1.5 ⭐⭐ — Learn 5 terminal commands on YOUR system
              (cd, ls/dir, mkdir, rm/del, clear/cls) and note what each does.
TASK 1.6 ⭐⭐ — Enable VS Code Auto Save, then verify: edit → compile
              immediately (without Ctrl+S) → new output appears.
TASK 1.7 ⭐⭐⭐ — Compile with  g++ -Wall -Wextra file.cpp -o file
              on an older Chapter-1 program and fix every warning it reports.
TASK 1.8 ⭐⭐⭐ — Write down YOUR personal "setup cheat sheet"
              (folder path, compile command, run command) on a sticky note
              or text file — from memory.
```

💡 **Done with all 8?** Your environment is officially a non-issue for the rest of the book.
